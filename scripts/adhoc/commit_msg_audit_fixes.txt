Issue #1 + #2: Phantom position cleanup + ACKED status drift
  src/core/database.py:
    + get_intents_for_reconciliation(days) — returns recent intents
      that may need broker reconciliation (status in SUBMITTED/ACKED/
      FILLED with broker_order_id, last N days)
  src/core/execution_engine.py:
    + _reconcile_optimistic_fills() — at start of every run, polls
      Alpaca for each recent intent and:
       - broker canceled/expired/rejected → reverse local position,
         mark intent FAILED (catches paper-OPG optimistic fills that
         never actually executed at the broker)
       - broker filled but local ≠ FILLED → update intent status
         (catches ACKED-but-actually-filled drift)
       - else → leave alone
    + _reverse_optimistic_fill(intent, broker_status) — handles the
      position reversal mechanics for BUY (subtract shares) and SELL
      (add shares back).
    * run_all_strategies() — calls _reconcile_optimistic_fills after
      _cancel_stale_orders, before data quality check.

  Backfill: scripts/adhoc/backfill_phantom_cleanup.py ran the new
  logic against current DB. Before: 4 open positions (ABBV, AMD, AMZN
  phantom + XLV real). After: 1 open (XLV BROKER_SYNC, matches broker
  exactly). 28 phantom intents marked FAILED.
